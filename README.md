安装三步搞定
一，拷贝：把 E:\ai\原神转服器\ 整个文件夹(或只拷 原神转服器.exe 这一个文件也行，资源全在内部)用 U盘 拷到目标电脑任意位置，比如桌面
二，双击运行 exe,首次点「自动查找」(全盘搜一次，约10~30秒)或「浏览…」手动选游戏目录(有 YuanShen.exe 的那个文件夹)
三，点「▶ 启动官服 / ▶ 启动B服」开始用
两个前提
目标电脑必须已经装了原神国服客户端(官服或B服装的都行，游戏从官方渠道装；本工具只切渠道，不带游戏本体)
Windows 10/11 直接可用(依赖的 .NET Framework 系统自带，零安装)
B服官服一键切换，目前可用，以后不知道，无任何其他内容仅限windos系统
